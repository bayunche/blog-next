# 文章列表页改造方案

## 页面目标
把 `/posts` 从“文章堆叠页”升级为“内容索引页”。

---

## 当前实现
文件：`src/app/posts/page.tsx`

当前已有：
- 搜索框
- 分页
- 文章卡片列表

当前问题：
1. 搜索有了，但分类筛选 UI 没真正完成
2. `selectedCategory` 和 `categories` 状态存在，但基本没落地使用
3. 摘要直接 `article.content.substring(...)`，会暴露 Markdown 残留
4. 列表页仍然只能按时间看，不够像内容导航页
5. 搜索、分类、标签、推荐之间缺少联动

---

## 必须有

### 1. 摘要统一清洗
当前：
- `summary={article.content.substring(0, 150) + '...'}`

建议：
- 改为统一使用 `stripMarkdown` 或公共 `getArticleExcerpt()`
- 去除标题符号、代码块、图片语法、Obsidian 图片引用

### 2. 增加分类筛选栏
页面头部建议增加：
- 全部
- Java
- Go
- Electron
- 前端
- 网安
- 生活 / 随笔

筛选应与搜索共存。

### 3. 强化“列表中的决策信息”
普通访客点文章前，最想知道：
- 这篇讲什么
- 难不难
- 是不是值得我看

建议在卡片中增加以下信息中的 1~2 项：
- 类型：入门 / 原理 / 实战 / 踩坑
- 系列名
- 阅读时长
- 是否精选

### 4. 减弱 `0 评论` 的展示存在感
建议：
- 评论数为 0 时不显示
- 或显示成更柔和的中性状态

---

## 应该有

### 1. 增加排序方式
建议支持：
- 最新发布
- 最多阅读
- 编辑精选

### 2. 增加“专题入口”
在搜索框下方增加专题导航：
- Java 学习路线
- Go 系列
- Electron 系列
- 前端性能

### 3. 增加空状态优化
当前空状态较基础。
建议对不同情况给出不同提示：
- 搜索为空：换关键词
- 分类为空：这个分类还没整理完成
- 数据为空：去首页看看推荐内容

---

## 加分项

### 1. 支持组合筛选
- 分类 + 搜索词
- 分类 + 标签

### 2. 增加“只看代表作 / 精选”开关
适合第一次来的用户快速筛选高质量内容。

---

## 推荐布局
1. 标题 + 总文章数
2. 搜索框
3. 分类筛选栏
4. 排序按钮
5. 精选专题入口
6. 文章列表
7. 分页

---

## 验收标准
列表页应让用户在 15 秒内快速定位到：
- 最新内容
- 某一类技术内容
- 一篇自己愿意点开的文章
