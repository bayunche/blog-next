# 首页改造方案

## 页面目标
让第一次进入站点的访客在 5~10 秒内完成三件事：
1. 知道你是谁
2. 知道你主要写什么
3. 知道接下来该点哪里

---

## 当前实现
文件：`src/app/page.tsx`

当前结构：
- `Hero`
- 最新文章列表（10 篇）
- 侧边栏 `Sidebar`
- “查看全部文章”按钮

当前问题：
1. 首页更像“主题展示页 + 最新文章流”，但不像“站点门面页”
2. 缺少一句明确的自我定位
3. 缺少“推荐阅读 / 热门 / 入门 / 系列”导航
4. 最新文章直接铺 10 篇，对新访客有点多
5. 内容排序只有“最新”，缺少“为什么先看这篇”的引导

---

## 必须有

### 1. 重做首屏文案
建议首屏明确写出：
- 你是谁
- 你写什么
- 内容类型

建议文案结构：
- 标题：落樱轻声
- 副标题：记录 Java / Go / Electron / 前端开发中的学习、实战与踩坑
- 次级说明：这里有学习笔记、原理整理、项目经验和折腾记录

### 2. 增加 CTA 按钮
建议首屏至少有 2~3 个入口：
- 从这里开始看
- 最新文章
- 关于我

### 3. 新增“推荐阅读”区块
建议在最新文章之前增加：
- 代表作 3 篇
- 或“新手先看”3 篇
- 或“热门文章”3 篇

这个区块比“最新文章”更能服务第一次来的访客。

### 4. 首页文章数减少到 6 篇以内
当前 10 篇略长。
建议：
- 推荐阅读 3 篇
- 最新文章 4~6 篇
- 底部再给“查看全部文章”

---

## 应该有

### 1. 新增专题导航区
建议在首页中部增加专题卡片：
- Java
- Go
- Electron
- 前端性能
- 网络安全

每个专题卡片包含：
- 名称
- 简短介绍
- 文章数
- 点击跳转分类或标签页

### 2. 首页加“作者能力标签”
例如：
- Java 后端
- Go 并发
- Electron 桌面端
- 前端性能优化

作用：快速建立作者画像。

### 3. 首页增加“最近在做什么”小区块
可以放：
- 最近更新了什么
- 正在学习什么
- 当前关注方向

会让首页更像一个活着的博客，而不是静态模板。

---

## 加分项

### 1. 做“阅读路径”
例如：
- 如果你想学 Java → 从这里开始
- 如果你想看 Go → 从这里开始
- 如果你想看 Electron → 看这个系列

### 2. 首页增加一条订阅/关注提示
例如：
- 欢迎订阅 RSS
- 在 GitHub 关注项目进展
- 收藏这个博客

---

## 推荐布局
1. Hero 首屏
2. 推荐阅读 / 代表作
3. 专题导航
4. 最新文章
5. About 简述 + 外链

---

## 落地建议

### 代码层面
- 保留 `Hero`，但增强文案与按钮
- 为首页新增推荐文章数据源（可先用手动配置）
- 最新文章数据量从 10 改为 4~6
- 为专题区创建独立组件，例如 `TopicGrid`

### 内容层面
- 选出 3 篇真正值得先看的文章做“代表作”
- 写一句明确、具体、不模板化的个人定位

---

## 验收标准
如果一个陌生访客打开首页后能立刻回答下面三个问题，说明首页改造成功：
1. 这是个什么博客？
2. 作者擅长什么？
3. 我下一步该点哪篇？
